# 🎪 F3R PRODUCCIONES S.A.S. - Sistema Cotizador & CRM de Eventos

Sistema integral para la cotización comercial, auditoría financiera, conciliación de costos y generación automatizada de propuestas ejecutivas oficiales en **PDF** y **Excel formulado** para **F3R Producciones S.A.S.**

---

## 🚀 Características Principales

- **Editor Comercial Inteligente:** Creación y modificación en tiempo real de ítems, cantidades, costos y precios de venta.
- **Validación Matemática Automática:** Subtotales, utilidades y márgenes formulados dinámicamente antes de exportar.
- **Exportación Oficial a PDF:** Diseño corporativo con identidad visual F3R (Negro Ónix, Blanco Ejecutivo y Dorado Metálico), numeración versionada (`V1-MMDD`, `V2-MMDD`), cuenta bancaria Bancolombia y condiciones comerciales completas.
- **Exportación a Excel Formulado:** Fórmulas nativas de Excel (`SUMA`, multiplicaciones automáticas) y formato de moneda contable.
- **Estructura de Almacenamiento Organizada:** Auto-guardado de documentos emitidos en carpetas dedicadas por cliente (`F3R_ARCHIVOS/`).
- **Base de Datos Persistente (CRM):** Histórico de eventos, cotizaciones y conciliaciones financieras almacenado en formato JSON (`crm_events_db.json`).

---

## 🛠️ Requisitos e Instalación

1. Clonar el repositorio:
   ```bash
   git clone https://github.com/f3rproducciones-hub/cotizador-f3r.git
   cd cotizador-f3r
   ```

2. Instalar dependencias:
   ```bash
   pip install -r requirements.txt
   ```

3. Ejecutar la aplicación:
   ```bash
   streamlit run app.py
   ```
   O ejecutar directamente con el archivo por lotes en Windows:
   ```cmd
   ejecutar_crm.bat
   ```
